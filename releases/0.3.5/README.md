# GatoLang 0.3.5

This release fixes the GC root corruption that affected class-method encryption workloads.

## Contents

- `SHA256SUMS`
- `gatoc.jar`
- `linux/`
- `linux.zip`
- `windows/`
- `windows.zip`

## Install

Linux user install:

```bash
cd releases/0.3.5
bash linux/install-user.sh
```

Linux system install:

```bash
cd releases/0.3.5
sudo bash linux/install.sh
```
